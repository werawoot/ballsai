## ตัวเลือก ก./ข. (เชิญสมาชิกเมื่ออีเมลยังไม่มีบัญชี) — รอเจ้าของเลือก

- **ข.** คงข้อความ "ยังไม่มีบัญชีนี้ในระบบ" แล้วจำกัดจำนวนครั้งที่เชิญต่อชั่วโมง
