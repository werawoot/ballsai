พบทางไปสมัครทีม · มีเงื่อนไขเลือกเป้าหมาย

เรียงปัญหาตามผลกระทบต่อรอบทดสอบ

1
ล็อกอินจริงยังไม่ผ่านการทดสอบ

ใน local mock ไม่ได้ส่ง OTP หรือยืนยัน Google; หากอีเมลไม่ถึง/จำกัดการส่ง ผู้ทดสอบหยุดตั้งแต่หน้าแรก. ต้องมีผู้ทดสอบ 1 บัญชีต่อวิธีและยืนยันการส่งถึงก่อนนัดกลุ่ม.

2
ผู้ปกครองสร้างตัวตนของลูกแทนไม่ได้

หน้า /guardian ต้องมีบัญชีนักกีฬาก่อน และลูกต้องตอบรับ. แจ้งลำดับนี้ก่อนส่งลิงก์ทดสอบ มิฉะนั้นจะถามใน LINE/ถอยออก.

3
การ์ดแรกยังไม่ใช่การ์ดที่มีชื่อ

/card แสดง preview ก่อนข้อมูลครบ. ช่องชื่ออยู่ในแท็บข้อมูลและปุ่มบันทึกปรากฏหลังแก้ ทำให้คนคิดว่าการ์ดเสร็จแล้วหรือไม่รู้ว่าต้องกดอะไร.

4
ผู้เยาว์อาจเข้าใจ “แชร์การ์ด” ว่าเปิดสาธารณะแล้ว

การ์ดส่วนตัวทำได้ แต่การเผยแพร่ต้องมีวันเกิดและความยินยอม. ต้องแยก “แชร์ภาพการ์ด” ออกจาก “เปิดโปรไฟล์สาธารณะ” ให้ชัด โดยคงข้อกำหนด/คำยินยอมเดิม.

5
หลัง Welcome ไม่มีคำว่า “สมัครทีม” โดยตรง

โค้ชไปต่อได้เมื่อเลือก “หารายการแข่ง”; จากนั้นต้องเปิดรายการก่อนเห็นปุ่มสมัคร. ความเสี่ยงระดับกลาง ไม่ใช่ blocker เมื่อเลือก goal แนะนำ.

6
เช็กจอ 320 px กับอุปกรณ์จริงก่อนเชิญกลุ่ม

mockup นี้จัดวางเป็นคอลัมน์เดี่ยวที่ 320/390 และ 3 คอลัมน์บนเดสก์ท็อป; ยังไม่ยืนยัน keyboard/OTP/เครือข่ายจริงหรือพฤติกรรม touch บนอุปกรณ์จริง.

ข้อเสนอที่ทำได้ก่อนผู้ทดสอบ (หลังเจ้าของอนุมัติ mockup เท่านั้น): เพิ่มคำแนะนำตำแหน่ง/ลำดับ “ลูกต้องสร้างบัญชีก่อน” บนเส้นทางผู้ปกครองโดยไม่แก้ข้อความยินยอม; ทำจุดบันทึกชื่อบน Player Card ให้มองเห็นว่าเป็นขั้นจำเป็น; แยกสถานะการ์ดส่วนตัวกับการเปิดสาธารณะให้สแกนเจอ. ทั้งหมดเป็นงาน UI เล็ก ไม่แตะ schema/สิทธิ์ และไม่เปลี่ยนกฎผู้เยาว์. รอได้: ปรับธีม/ภาพตกแต่ง, รูปแบบการ์ด, และเส้นทางโค้ชหลังมีผลทดสอบจริง. ยังไม่มีการแก้โค้ดแอป.
