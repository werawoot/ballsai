ใช้คู่กับ [runbook ข้อ 6](closed-beta-runbook.md) (W1 หลัก: login → ทีม → สลิป → ผลแข่ง)
สคริปต์นี้ทดสอบเครื่องมือโค้ช 7 รอบที่ลง Production แล้ว (9–11 ต.ค. 2026):
ประเมินทักษะ, นัดหมายและเช็กชื่อ, ประกาศ, แผนซ้อม, โน้ตโค้ช, นาทีลงเล่น และผู้ช่วยโค้ช

**เป้าหมาย:** คนจริง 5 คนใช้เครื่องมือโค้ชครบหนึ่งรอบด้วยตัวเอง โดยไม่ต้องมีนักพัฒนาช่วยกลางทาง
และพิสูจน์ว่า **ข้อมูลเด็กไปถึงเฉพาะคนที่ควรเห็น**

ยังไม่มีผลทดสอบจริง เอกสารนี้คือแผน ไม่ใช่หลักฐาน ห้ามเรียกว่าผ่าน 100% จนกว่ากลุ่มทดสอบจะทำครบทุกข้อ (AGENTS.md ข้อ 11)

## 4. หยุดทันทีถ้าเจอ (Severity 1)

หยุดทดสอบ ถ่ายภาพหน้าจอ แจ้งทีมงานใน LINE **ห้ามแก้ข้อมูลในฐานข้อมูลเอง**

- ผู้ช่วยโค้ชเห็นโน้ตโค้ช การประเมินทักษะ หรืออีเมลของใคร
- นักกีฬาเห็นโน้ต นาทีลงเล่น หรือคำตอบนัดของนักกีฬาคนอื่น
- ผู้ปกครองเห็นข้อมูลของเด็กที่ไม่ใช่ลูกตัวเอง
- คนที่ไม่ได้อยู่ในทีม เปิดหน้าทีมได้ด้วยลิงก์
- ผู้ช่วยที่ถูกถอดแล้ว ยังบันทึกหรือเห็นอะไรในทีมได้
- โน้ตที่มีคำเรื่องสุขภาพบันทึกผ่าน
- คะแนนประเมินขึ้นการ์ดโดยที่นักกีฬายังไม่กดยอมรับ
