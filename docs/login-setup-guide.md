## ขั้น 1: เปิด Google ให้ทุกคนใช้ (ได้ผลมากที่สุด)

> **เสร็จแล้ว 14 ต.ค. 2026:** โปรเจกต์ Google Cloud `BallDoenSai` เปลี่ยนเป็น In production แล้ว Scopes มีแค่ openid, email, profile ลิงก์ Privacy และ Terms ตรง Google ไม่ขอตรวจสอบแอป ไม่ได้แตะ Client secret, API key หรือ redirect URIs (เจ้าของทำผ่าน ChatGPT)
> ยังต้องทำ: ลองเข้าด้วย Gmail ที่ไม่ใช่ Test user ในหน้าต่าง Incognito

1. Google Cloud Console → เลือกโปรเจกต์ที่ใช้กับ Supabase → **Google Auth Platform** (หรือ APIs & Services → OAuth consent screen)
2. **Branding:** ตรวจชื่อแอป อีเมลติดต่อ โลโก้ และลิงก์หน้า `/privacy` กับ `/terms` ของโดเมนจริง
3. **Data access (Scopes):** ให้มีแค่ `openid`, `email`, `profile` ถ้ามีอย่างอื่น ให้ลบออก
4. **Audience:** กด **Publish app** (เปลี่ยนจาก Testing เป็น In production)
5. ถ้า Google ขอให้ตรวจสอบแอป ให้หยุดแล้วแคปหน้าจอมาให้ผู้ช่วยดู ห้ามส่งข้อมูลบัตรหรือ secret

ก่อนกด ให้ตรวจข้อกำหนดล่าสุดของ Google เพราะขั้นตอนเปลี่ยนได้ ถ้าใช้แค่ scope พื้นฐาน มักไม่ต้องผ่านการตรวจแบบเต็ม
หลังกด ให้ลองเข้าด้วยบัญชี Gmail ที่ไม่ได้เป็น Test user ทั้งบน Staging และ Production

## ขั้น 2: ให้รหัสทางอีเมลมาทุกครั้ง (ก่อนผู้ทดสอบ W1)

ต้องมีโดเมนของเราเองก่อน เช่น balldoensai.com ถ้ายังไม่มีให้ซื้อก่อน

1. สมัครบริการส่งอีเมล เช่น Resend แล้วยืนยันโดเมน โดยเพิ่ม DNS record ตามที่บริการบอก
2. สร้าง SMTP credentials ในบริการนั้น และห้ามส่งค่าให้ผู้ช่วย
3. Supabase **Staging** (`vorpnkedpscsqhnrssrl`) → Authentication → **Emails** → **SMTP Settings** → เปิด Custom SMTP แล้วใส่ host, port, user, password และผู้ส่ง เช่น `no-reply@<โดเมน>` กับชื่อ `BallDoenSai`
4. Authentication → **Rate Limits:** ตั้งจำนวนอีเมลต่อชั่วโมงให้พอกับผู้ทดสอบ
5. ลองขอรหัสบน Staging ด้วยอีเมลที่ไม่ใช่สมาชิกทีม Supabase ถ้ารหัสมา ให้ทำซ้ำบน **Production** (`hivedzrwrrcnjrlirhtv`) เมื่อเจ้าของอนุมัติแยก

## ขั้น 3: ลดรหัสเหลือ 6 หลัก (ถ้าต้องการ)

Supabase → Authentication → Providers → Email → **Email OTP Length** = 6
แอปรับรหัส 6–10 หลักอยู่แล้ว (`lib/otp.ts`) ไม่ต้องแก้โค้ด แต่ช่องรหัสยังแสดง 8 ช่อง
ถ้าเปลี่ยนเป็น 6 หลัก ให้บอกผู้ช่วย แล้วผู้ช่วยจะปรับจำนวนช่องให้ตรง

## ระหว่างรอ: บัญชีทดสอบบน Staging (ไม่ต้องรอ OTP)

ใช้บน **Staging เท่านั้น**

1. Supabase Staging → Authentication → Users → **Add user** → ใส่อีเมล เช่น `topkung72+coach@gmail.com` และรหัสผ่าน → ติ๊ก **Auto Confirm User**
2. เว็บ Staging → `/login?admin=1` → ล็อกอินด้วยอีเมลและรหัสผ่านนั้น ถ้าเว็บพาไป `/admin` แล้วเข้าไม่ได้ ไม่เป็นไร
