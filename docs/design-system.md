# BallDoenSai design system (v1, 30 ก.ย. 2026)

ใช้กับทุกหน้าที่ปรับใหม่ ยกเว้นหน้าแรก (AGENTS.md กฎข้อ 7) ซึ่งเป็นต้นแบบของภาษาภาพนี้อยู่แล้ว
โค้ด: `app/ui.css` (tokens + ชิ้นส่วน `ui-*`), `components/BrandMark.tsx`
ลำดับงาน: `docs/user-flows.md` · ชุดที่ 1 = เข้าสู่ระบบ, ตั้งค่าครั้งแรก, โปรไฟล์ (+ Player Card)

## หลัก 6 ข้อ

1. **แบรนด์เดียว** — โลโก้ = สี่เหลี่ยมแดงเฉียงมีถ้วย + `BallDoenSai.com` (ตัวอักษรขาว ไม่มี ".com" สีทอง) ใช้ `BrandMark` เสมอ
2. **สองพื้นผิว**
   - **Stadium** (พื้นเข้ม `--ui-ink`) สำหรับช่วงสร้างตัวตนและอารมณ์: เข้าสู่ระบบ, ตั้งค่าครั้งแรก, Player Card, หัวโปรไฟล์ — ใส่ `ui-dark` ที่ราก
   - **Paper** (พื้นครีม `--ui-paper` + การ์ดขาว) สำหรับอ่านและกรอก: รายการ, Ranking, ฟอร์ม, แดชบอร์ดผู้จัด — อ่านง่ายกลางแดดในสนาม
3. **หัวข้อไทยตัวทึบเสมอ** (Sarabun 800) ห้ามตัวอักษรเส้นขอบ ตัวเลขใช้ Oswald ป้ายเล็กภาษาอังกฤษใช้ Barlow Condensed
4. **ปุ่มหลักหนึ่งปุ่มต่อจอ** (`ui-btn-primary` แดง) ที่เหลือเป็นปุ่มรอง บนมือถือปุ่มหลักอยู่ในระยะนิ้วโป้ง (ล่างจอ)
5. **ทุกตัวเลขบอกที่มา** (กฎข้อ 8) ด้วยป้าย `ui-chip`: `is-performance` ผลแข่งยืนยัน (เขียว) · `is-coach` โค้ชยืนยัน (น้ำเงิน) · `is-self` กรอกเอง (เทา) · `is-warn` รอดำเนินการ เช่น รอผู้ปกครองยินยอม (เหลือง) ค่าที่ยังไม่มีแสดง "—" ไม่ใช่ค่าสมมติ
6. **บอกทางไปต่อเสมอ** — จุดที่ผู้ใช้ติด (ยังไม่ยินยอม, ยังไม่มีผลแข่ง, รายการว่าง) ต้องมีข้อความว่าทำอะไรต่อและปุ่มไปทำ

## ชิ้นส่วน

| class | ใช้ทำ |
| --- | --- |
| `ui-brand` + `BrandMark` | โลโก้ในหัวหน้า |
| `ui-eyebrow`, `ui-hero`, `ui-h1`, `ui-h2`, `ui-num` | ตัวอักษร |
| `ui-btn` + `ui-btn-primary` / `-white` / `-ghost` / `-ghost-d` / `-sm` | ปุ่ม สูงอย่างน้อย 44–54px |
| `ui-field` (label ห่อ `<span>` + `<input>`) | ช่องกรอกที่ป้ายอยู่ในกรอบ |
| `ui-option` + `-icon` / `-text` / `-tick`, `.is-selected` | ตัวเลือกใหญ่แตะด้วยนิ้วโป้ง (ใช้ `aria-pressed`) |
| `ui-progress` | แถบความคืบหน้าหลายขั้น |
| `ui-chip` | ป้ายที่มาของข้อมูล / สถานะ |
| `ui-card` | การ์ดบน Paper |

## ความเข้าถึงได้

- เป้ากดอย่างน้อย 44px · focus ring ทอง 3px (`:focus-visible`) · รองรับ `prefers-reduced-motion`
- ตัวเลือกใช้ `aria-pressed`, แถบความคืบหน้าใช้ `role="progressbar"`, ข้อความผิดพลาด `role="alert"`
- ข้อความทั้งหมดของหน้าที่แปลแล้วอยู่ใน `messages/*.json` (ADR-009)
