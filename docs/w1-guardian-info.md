# ข้อมูลสำหรับผู้ปกครอง: ลูกของคุณกับ BallDoenSai

ใช้ประกอบการชวนผู้ปกครองในรอบทดสอบ W1 ([แผน W1](w1-pilot-plan.md))

> เอกสารนี้อธิบายการทำงานของระบบเป็นภาษาง่าย **ไม่ใช่ข้อความทางกฎหมาย**
> นโยบายความเป็นส่วนตัวฉบับจริงอยู่ที่หน้า `/privacy` ของเว็บ และข้อความยินยอมที่ผู้ปกครองกดในระบบ
> เป็นฉบับที่ใช้จริง (กำลังให้นักกฎหมายตรวจ, T25) เอกสารนี้ไม่แก้หรือแทนถ้อยคำเหล่านั้น
> ข้อความในข้อ "กติกาความปลอดภัย" ยกมาจากหน้าเว็บตามตัวอักษร

## ระบบเก็บอะไรของลูก และใครเห็น

| ข้อมูล | ใครเห็น |
| --- | --- |
| ชื่อที่แสดง, ตำแหน่ง, จังหวัด, ทีม | ทุกคน **เฉพาะเมื่อเปิดโปรไฟล์สาธารณะ** (ต้องมีความยินยอมของผู้ปกครองก่อน) |
| วันเกิด | ลูกเท่านั้น หน้าอื่นแสดงแค่อายุ |
| รูปโปรไฟล์ | เปิดผ่านลิงก์ชั่วคราวหลังตรวจสิทธิ์เท่านั้น |
| ผลแข่ง, คะแนนฝีมือ, แต้ม, เหรียญ | ทุกคน เฉพาะเมื่อโปรไฟล์เปิด; ถ้าโปรไฟล์ส่วนตัว ลูกเห็นเองคนเดียว |
| การเชื่อมบัญชีผู้ปกครองกับลูก และเวลาที่ยินยอม | คุณกับลูก |
| แจ้งเตือนในระบบ | เจ้าของบัญชีเท่านั้น |

โค้ชเห็นชื่อที่แสดง ตำแหน่ง และปีเกิดของเด็กที่ขอเข้าทีม ไม่เห็นอีเมล เบอร์โทร หรือวันเกิดเต็ม

## กติกาความปลอดภัย (ข้อความจากหน้าเว็บ)

- **ผู้ปกครองต้องยินยอมก่อน:** โปรไฟล์ของน้องที่อายุต่ำกว่า 20 ปีเปิดให้คนทั่วไปเห็นไม่ได้ จนกว่าผู้ปกครองจะยินยอม
- **รูปและวันเกิดไม่เปิดสาธารณะ:** รูปนักกีฬาเปิดผ่านลิงก์ชั่วคราวหลังตรวจสิทธิ์ หน้าโปรไฟล์สาธารณะแสดงอายุ ไม่แสดงวันเกิด
- **ไม่เก็บข้อมูลสุขภาพ:** ก่อนซ้อม ระบบถามว่า "ตอนนี้เจ็บไหม" เพื่อให้น้องหยุดก่อนถ้าเจ็บ แต่ไม่บันทึกคำตอบไว้ที่ใดเลย

## สิ่งที่ผู้ปกครองทำได้

1. **ถ้าลูกยังไม่มีอีเมลของตัวเอง:** สร้างบัญชีให้ลูกด้วยอีเมลแยกที่คุณเปิดอ่านได้ เช่น ถ้าใช้ Gmail
   ใส่ `ชื่อคุณ+ชื่อลูก@gmail.com` แล้วเข้าสู่ระบบด้วยรหัส OTP ที่ส่งเข้ากล่องอีเมลของคุณ ลูกหลายคนใช้คนละชื่อหลังเครื่องหมายบวก
   บัญชีของลูกใช้บนโทรศัพท์ของลูกหรือของคุณเท่านั้น **อย่าให้โค้ชหรือใครรู้รหัสเข้าระบบของลูก**
2. **คุณมีบัญชีผู้ปกครองของตัวเองแยกเสมอ** (อีเมลหลักของคุณ) แล้ว**เชื่อมบัญชีกับลูก** ที่หน้า `/guardian` และลูกกดตอบรับ
3. **ยินยอมหรือไม่ยินยอม** ให้เปิดโปรไฟล์สาธารณะ ถ้าไม่ยินยอม ลูกยังร่วมทีมและลงแข่งได้ แต่โปรไฟล์เป็นแบบส่วนตัว
4. **ได้แจ้งเตือน** ทุกครั้งที่ลูกมีผลแข่ง ได้เหรียญ หรือติดหอเกียรติยศ
5. **ให้ลูกออกจากทีมแทนได้** จากหน้า "ทีมของฉัน"
6. **ลบข้อมูลนักกีฬาของลูก** ได้จากหน้า `/profile` ของลูก

## ไม่มี

- ไม่มีโฆษณา
- ไม่ขายหรือส่งข้อมูลเด็กให้แบรนด์หรือใครภายนอก
- เด็กไม่ต้องจ่ายเงิน

ถ้าต้องการถอนความยินยอมระหว่างทดสอบ แจ้งโค้ชหรือทีมงานได้ทันที ทีมงานจะหยุดการทดสอบส่วนนั้นก่อน
