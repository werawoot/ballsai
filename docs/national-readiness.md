# ความพร้อมใช้งานระดับประเทศ

เป้าหมายของ BallDoenSai.com คือให้คนทั้งประเทศใช้ได้ (ดู `AGENTS.md` หัวข้อ "Target:
nationwide use") เอกสารนี้คือรายการที่ต้องมี **หลักฐาน** ก่อนจะบอกว่าระบบพร้อม
ใช้ระดับประเทศ อัปเดตสถานะเมื่อมีหลักฐานใหม่ และใส่ลิงก์หรือที่มาของหลักฐานไว้ด้วย

สถานะ: ✅ ผ่าน (มีหลักฐาน) · ⚠️ มีบางส่วน · ❌ ยังไม่ผ่าน · ❓ ยังไม่รู้ ต้องตรวจ

สถานะตั้งต้น ณ 28 กันยายน 2026 (`main` ที่ `189d6c1`) มาจากการอ่านโค้ดและเอกสารใน repo
ไม่ได้มาจากการวัดระบบจริง

## เป้าหมายที่ต้องกำหนดก่อน

ไม่มีตัวเลขเหล่านี้ load test จะไม่มีเกณฑ์ผ่าน — เจ้าของโปรเจกต์เป็นผู้กำหนด

| ตัวเลข | ค่า |
| --- | --- |
| นักกีฬาในปีแรก | ❓ |
| ผู้ใช้พร้อมกันช่วงพีค (เช่นวันแข่งหลายจังหวัดพร้อมกัน) | ❓ |
| แพ็กเกจ Supabase / Vercel ที่ใช้ | ❓ |
