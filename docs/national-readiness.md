# ความพร้อมใช้งานระดับประเทศ

เป้าหมายของ BallDoenSai.com คือให้คนทั้งประเทศใช้ได้ (ดู `AGENTS.md` หัวข้อ "Target:
nationwide use") เอกสารนี้คือรายการที่ต้องมี **หลักฐาน** ก่อนจะบอกว่าระบบพร้อม
ใช้ระดับประเทศ อัปเดตสถานะเมื่อมีหลักฐานใหม่ และใส่ลิงก์หรือที่มาของหลักฐานไว้ด้วย

สถานะ: ✅ ผ่าน (มีหลักฐาน) · ⚠️ มีบางส่วน · ❌ ยังไม่ผ่าน · ❓ ยังไม่รู้ ต้องตรวจ

สถานะตั้งต้น ณ 28 กันยายน 2026 (`main` ที่ `189d6c1`) มาจากการอ่านโค้ดและเอกสารใน repo
ไม่ได้มาจากการวัดระบบจริง

## เป้าหมายที่ต้องกำหนดก่อน

ไม่มีตัวเลขเหล่านี้ load test จะไม่มีเกณฑ์ผ่าน — เจ้าของโปรเจกต์เป็นผู้กำหนด

| ตัวเลข | ค่า |
| --- | --- |
| นักกีฬาในปีแรก | ❓ |
| ผู้ใช้พร้อมกันช่วงพีค (เช่นวันแข่งหลายจังหวัดพร้อมกัน) | ❓ |
| แพ็กเกจ Supabase / Vercel ที่ใช้ | ❓ |

## 1. รับคนพร้อมกันได้

| รายการ | สถานะ | หลักฐาน / หมายเหตุ |
| --- | --- | --- |
| Load test ถึงพีคที่กำหนด: p95 และอัตรา error อยู่ในเกณฑ์ | ❌ | ยังไม่มีสคริปต์ load test ใน repo |
| หน้ารายการแบ่งหน้า | ❌ | `/venues` และ `/tournaments` ดึงทุกแถวในครั้งเดียว (`/venues` ดึงสนาม+คอร์ท+ช่วงเวลาทั้งหมด) |
| Query ที่ใช้บ่อยตรวจด้วย `EXPLAIN` แล้วใช้ index | ⚠️ | มี `create index` ใน 30 ไฟล์ SQL แต่ยังไม่ได้ตรวจกับ query จริง |
| ตัวกรองจังหวัดใน ranking ไม่อ่านทั้งตาราง | ❌ | `getPublicRankingProvinces` อ่าน `province` ของ `player_ranks` ทุกแถวในฤดูกาล แล้วค่อยตัดซ้ำในโค้ด |
| รู้เพดานของแพ็กเกจ Supabase และ Vercel | ❓ | |

## 2. ข้อมูลถูกต้องเมื่อมาก

| รายการ | สถานะ | หลักฐาน / หมายเหตุ |
| --- | --- | --- |
| ไม่มีการตัดข้อมูลเงียบ ๆ | ❌ | `lib/public-data.ts`: Hall of Fame อ่าน 250 โปรไฟล์, ข้อมูล identity 500 แถว; query ที่ไม่ใส่ `limit` (รายการสนาม, รายการแข่ง, จังหวัดใน ranking) จะถูก API ของ Supabase ตัดที่เพดาน max rows ของโปรเจกต์ (ค่าเริ่มต้น 1,000) โดยไม่มี error — ต้องตรวจค่าที่ตั้งจริง |
| การกดพร้อมกันไม่ทำให้ข้อมูลซ้ำหรือชน | ⚠️ | RPC หลายตัวมีการ guard แต่ยังไม่เคยทดสอบแบบพร้อมกัน |
| หลายจังหวัดเปิดฤดูกาลของตัวเองได้ | ❌ | `lib/season.ts` มีฤดูกาลเดียวทั้งประเทศ |

## 3. ความปลอดภัย

| รายการ | สถานะ | หลักฐาน / หมายเหตุ |

| ตรวจ dependency, สแกน secret, pen test ภายนอก | ❌ | |

## 10. พิสูจน์กับคนจริงเป็นขั้น

ข้ามขั้นไม่ได้ ขั้นถัดไปเริ่มได้เมื่อขั้นก่อนผ่านเกณฑ์แล้วเท่านั้น

| ขั้น | ผู้ใช้ | เกณฑ์ผ่าน | สถานะ |
| --- | --- | --- | --- |
| W1 | 5 | ผลแข่งจริง 1 นัดทำให้ XP, Badge, Ranking ขยับครบ (runbook §6) | ❌ ยังไม่เริ่ม |
| W2 | 20 | ไม่มี blocker ค้างใน production logs | ❌ |
| นำร่องหนึ่งจังหวัด | หลักร้อย | ผู้จัดใช้เองจนจบหนึ่งฤดูกาล | ❌ |
| ภูมิภาค | หลักพัน | load test ผ่านที่ 3–5 เท่าของพีคที่วัดได้จริง | ❌ |
| ทั่วประเทศ | ตามเป้า | ทุกหมวดข้างบนเป็น ✅ | ❌ |
