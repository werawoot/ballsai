# ข้อมูลสำหรับนักกฎหมาย: นโยบายความเป็นส่วนตัวและข้อกำหนดการใช้งาน BallDoenSai.com

จัดทำ 8 ต.ค. 2026 จากโค้ดและฐานข้อมูลจริง (สถานะหลัง PR ที่ตั้ง region ของ server เป็น Singapore)
เอกสารนี้เป็น**ข้อเท็จจริงของระบบ**เพื่อให้นักกฎหมายเขียน `/privacy`, `/terms` และข้อความยินยอม
ไม่ใช่ร่างข้อความทางกฎหมาย ทีมพัฒนาไม่เขียนหรือแปลข้อความทางกฎหมายเอง (กติกาของเจ้าของโปรเจกต์)
งานที่เกี่ยวข้องใน `docs/national-readiness.md`: T24 (DPO และการแจ้งเหตุ), T25 (ตรวจข้อความ), T26 (ส่งข้อมูลข้ามแดน), T27 (ทดสอบความยินยอมผู้ปกครอง), T28 (การลบบัญชี)

## 1. ใครใช้ระบบ

- นักกีฬาเยาวชนไทย ส่วนใหญ่อายุต่ำกว่า 18 ปี (ระบบรับอายุ 5–80 ปี)
- ผู้ปกครอง, โค้ช, ผู้จัดการแข่งขัน, เจ้าของสนาม, ผู้สนับสนุน (สปอนเซอร์)
- ผู้ชมทั่วไปที่ไม่ได้ล็อกอิน เห็นเฉพาะข้อมูลสาธารณะ

## 2. ข้อมูลที่เก็บ

## 3. กฎที่ระบบบังคับอยู่แล้ว (ให้นโยบายเขียนตรงกับระบบ)

- โปรไฟล์นักกีฬาเปิดสาธารณะไม่ได้ ถ้าไม่มีวันเกิด
- ผู้เยาว์ (ต่ำกว่า 18) เปิดสาธารณะไม่ได้ ถ้าไม่มีการบันทึกความยินยอมของผู้ปกครอง บังคับทั้งในหน้าเว็บและใน trigger ของฐานข้อมูล (`sql/guardian-consent-enforcement-v1.sql`)
- ผู้ใช้ลบข้อมูลนักกีฬาของตัวเองได้จาก `/profile` (`delete_my_athlete_data()`) ส่วนการลบบัญชีล็อกอินเป็นคำขอให้แอดมินดำเนินการ (`account_deletion_requests`) เพราะแอปไม่ถือกุญแจ service role
- ข้อมูลตัวอย่างไม่แสดงบนเว็บจริง

## 4. ที่เก็บและผู้ให้บริการภายนอก

| ผู้ให้บริการ | ใช้ทำอะไร | ที่ตั้ง |
|---|---|---|
| Supabase | ฐานข้อมูล, ล็อกอิน, เก็บไฟล์ | Singapore `ap-southeast-1` (Production และ Staging) |
| Vercel | รันเว็บ | server function ที่ Singapore `sin1` (ตั้งใน `vercel.json`); ไฟล์หน้าเว็บกระจายผ่าน CDN ทั่วโลก |
| Google | ล็อกอินด้วย Google | ต่างประเทศ |
| Resend | ส่งอีเมล (ถ้าตั้งค่า) | ต่างประเทศ |
| Upstash Redis | จำกัดจำนวนคำขอ (rate limit) เก็บ IP/คีย์ชั่วคราว | ตามที่ตั้งค่าใน Upstash (ยังไม่ยืนยัน) |
| Cloudflare Turnstile | CAPTCHA ก่อนขอ OTP (ยังปิดอยู่) | ต่างประเทศ |
| Unsplash, ch7.com | รูปประกอบหน้าแรก โหลดตรงจากเบราว์เซอร์ผู้ใช้ (เห็น IP ผู้ใช้) | ต่างประเทศ |
| Vercel Analytics, Speed Insights | นับการเข้าชมหน้าและวัดความเร็ว (`app/layout.tsx`) | ต่างประเทศ |

คุกกี้: คุกกี้ล็อกอินของ Supabase และคุกกี้ภาษา `NEXT_LOCALE` ไม่มีโฆษณา มี Vercel Analytics และ Speed Insights ซึ่งนับการเข้าชมและความเร็วของหน้า

## 5. คำถามที่ต้องให้นักกฎหมายตอบ

1. ฐานทางกฎหมายในการเก็บข้อมูลผู้เยาว์ และรูปแบบความยินยอมของผู้ปกครองที่ระบบบันทึกอยู่ (ติ๊กยินยอม + เวลา) เพียงพอตาม PDPA หรือไม่ ต้องเก็บหลักฐานเพิ่มอะไร
2. การเก็บและประมวลผลที่ Singapore เป็นการส่งข้อมูลไปต่างประเทศ (มาตรา 28–29) ต้องเขียนอะไรในนโยบาย และต้องขอความยินยอมแยกหรือไม่ (T26)
3. ระยะเวลาเก็บข้อมูลแต่ละประเภท (สลิปโอนเงิน, ผลแข่ง, Highlight) ควรกำหนดเท่าไร ระบบยังไม่มีการลบอัตโนมัติ
4. ผลแข่งและอันดับที่แสดงสาธารณะของผู้เยาว์ ต้องมีเงื่อนไขเพิ่มหรือไม่
5. การลบบัญชีที่ต้องรอแอดมิน ใช้ได้ตามกฎหมายหรือไม่ และต้องเสร็จภายในกี่วัน (T28)
6. ใครเป็นผู้ควบคุมข้อมูลและ DPO และช่องทางติดต่อที่ต้องแสดง (T24)
7. ข้อกำหนดการใช้งาน: ความรับผิดเรื่องค่าสมัครและการจองสนาม, เนื้อหา Highlight ที่ผู้ใช้อัปโหลด, การระงับบัญชี
8. รูปหลักของหน้าแรกมาจากแกลเลอรี 7HD Champions Cup 2024 (`cdni-hw.ch7.com`, `app/globals.css`) และมีเด็กในภาพ ได้รับอนุญาตให้ใช้หรือไม่ ถ้าไม่ ต้องเปลี่ยนรูป

## 6. สิ่งที่ต้องส่งกลับมา

- ข้อความ `/privacy` และ `/terms` ฉบับไทย (และอังกฤษ ถ้าต้องการ) ที่นักกฎหมายรับรอง
- ข้อความในช่องติ๊กยินยอม 2 จุด: หน้าเข้าสู่ระบบ และหน้าผู้ปกครอง
- ทีมพัฒนาจะนำข้อความไปใส่ตามตัวอักษร โดยไม่แก้ถ้อยคำ
